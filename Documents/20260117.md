## 2. 핵심 공식

### 2.1 검 전투력
```
power = basePower × powerMultiplier^level
```

### 2.2 게이지 속도
```
// 일반
speed = baseSpeed + (level × speedIncrease)

// 피버
speed = (baseSpeed + (level × speedIncrease)) × feverMultiplier
```

### 2.3 판정 영역 (업그레이드 적용)
```
yellowZone = [start, end + Σ(upgrade.yellowBonus × upgrade.level)]
redZone = [start, end + Σ(upgrade.redBonus × upgrade.level)]
```

### 2.4 대성공 확률 (업그레이드 적용)
```
successChance = baseChance 
                + (isDanger ? dangerBonus : 0)
                + Σ(upgrade.successBonus × upgrade.level)

plusTwoChance = baseChance + Σ(upgrade.plusTwoBonus × upgrade.level)
plusThreeChance = baseChance + Σ(upgrade.plusThreeBonus × upgrade.level)
```

### 2.5 망치 시퀀스 확률
```
longChance = baseChance
             + (inRedZone ? redBonus : 0)
             + (level >= threshold ? highLevelBonus : 0)

count = (Random.value < longChance) ? longCount : baseCount
```

### 2.6 시작 레벨 (업그레이드 적용)
```
startLevel = Σ(upgrade.startLevelBonus × upgrade.level)
```

### 2.7 업그레이드 비용
```
cost = baseCost × costMultiplier^currentLevel
```

### 2.8 웨이브 스케일링 (무한 모드)
```
hp = baseHP × hpMultiplier^iteration
damage = baseDamage × damageMultiplier^iteration
gold = baseGold × goldMultiplier^iteration
count = baseCount + (countIncrement × iteration)
```

### UpgradeData.cs
```csharp
public enum UpgradeType
{
    ZoneExpansion,
    GreatSuccessBonus,
    StartLevel
}

[CreateAssetMenu(fileName = "Upgrade", menuName = "Config/Upgrade")]
public class UpgradeData : ScriptableObject
{
    public string upgradeName;
    [TextArea] public string description;
    public UpgradeType type;
    
    [Header("Cost: baseCost × costMultiplier^currentLevel")]
    public int baseCost = 100;
    public float costMultiplier = 1.5f;
    public int maxLevel = 10;
    
    [Header("Effect Per Level")]
    public float yellowZoneIncreasePerLevel = 0.05f;
    public float redZoneIncreasePerLevel = 0.03f;
    [Range(0, 1)] public float greatSuccessChancePerLevel = 0.05f;
    [Range(0, 1)] public float plusTwoChancePerLevel = 0.02f;
    [Range(0, 1)] public float plusThreeChancePerLevel = 0.01f;
    public int startLevelBonusPerLevel = 1;
    
    public int GetCost(int currentLevel)
    {
        return Mathf.RoundToInt(baseCost * Mathf.Pow(costMultiplier, currentLevel));
    }
}
```

## 5. 구현 우선순위

### Priority 1 - 기본 게임 루프
1. `GaugeController.StartGauge/StopGauge` - 게이지 왕복
2. `SmithingResult.Evaluate` - 판정 로직 (업그레이드 보너스 포함)
3. `Enemy.Initialize/Update` - 적 이동
4. `SwordSlot.TryAttack` - 자동 공격
5. `GridSystem` - 그리드 및 경로 생성

### Priority 2 - 핵심 연출
6. `HammerSequence.Play` - 망치 사운드 연출
7. `FeverSystem` - 피버 발동 및 관리
8. `DangerSystem` - Danger 판정 및 UI 연출

### Priority 3 - 시스템 완성
9. `DefenseManager.PlaceSword` - 검 배치 정렬
10. `UpgradeManager` - 업그레이드 구매 및 보너스 계산
11. `EnemySpawner` - 웨이브 생성 및 스케일링
12. `CoreHealth` - 코어 HP 및 게임오버
