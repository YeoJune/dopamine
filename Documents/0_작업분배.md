# 📋 작업 분배 세트

---

## 🎯 분배 전략

각 세트는 **독립적으로 구현 및 테스트 가능**하도록 구성. 세트 간 의존성 최소화.

---

## 📦 **SET 1: 코어 시스템 & 데이터** (기반 작업)
**담당자: 1명 (경험 많은 개발자 권장)**  
**예상 시간: 3-4시간**

### 파일 목록
1. `GameManager.cs` - 매니저 초기화 및 연결
2. `GameConfig.cs` - ScriptableObject 생성
3. `CurrencyManager.cs` - 골드 증감 로직
4. `AudioManager.cs` - 사운드 재생 레거시
5. `Sword.cs` - 검 전투력 계산

### 구현 내용
- GameManager에서 모든 매니저 Initialize 호출
- GameConfig.asset 생성 및 초기값 설정
- CurrencyManager의 AddGold/SpendGold 구현
- Sword 생성자에서 전투력 공식 적용

### 완료 기준
```csharp
// 테스트 코드
var sword = new Sword(5, config);
Debug.Log(sword.power); // 305.17... (100 × 1.25^5)

CurrencyManager.Instance.AddGold(100);
Debug.Log(CurrencyManager.Instance.GetGold()); // 100
```

## 📦 **SET 2: 강화 시스템** (게임 핵심 1)
**담당자: 1명**  
**예상 시간: 5-6시간**  
**의존성: SET 1 완료 필요**

### 파일 목록
1. `GaugeController.cs` - 게이지 왕복 로직
2. `SmithingResult.cs` - 판정 및 확률 계산
3. `HammerSequence.cs` - 망치 사운드 연출
4. `FeverSystem.cs` - 피버 모드 관리
5. `SmithingManager.cs` - 강화 전체 플로우 통합
6. `SmithingUI.cs` - UI 연결 및 업데이트

### 구현 내용
- GaugeController: Update()에서 게이지 왕복, 방향 전환
- SmithingResult: 공식 2.3, 2.4, 2.5 모두 구현
- HammerSequence: Coroutine으로 사운드 재생
- FeverSystem: 대성공 카운트 및 타이머 관리
- SmithingManager: OnGaugeStop → Evaluate → Play → ApplyResult 플로우
- SmithingUI: 버튼 이벤트, 게이지/레벨 표시

### 완료 기준
```
1. Space 입력 시 게이지 왕복 시작
2. Space 재입력 시 판정 및 망치 사운드 재생
3. 결과에 따라 레벨 증가 또는 0강으로 파괴
4. 대성공 3회 시 피버 발동, 30초 후 종료
```

## 📦 **SET 3: 그리드 & 경로 시스템** (게임 핵심 2)
**담당자: 1명 (알고리즘 강한 개발자 권장)**  
**예상 시간: 4-5시간**  
**의존성: SET 1 완료 필요**

### 파일 목록
1. `GridSystem.cs` - 그리드 생성 및 경로 캐싱
2. `Enemy.cs` - 경로 따라 이동
3. `WavePattern.cs` - ScriptableObject 생성
4. `EnemySpawner.cs` - 웨이브 생성 및 스케일링

### 구현 내용
- GridSystem.Initialize(): 10×10 그리드 생성, 외곽 테두리 좌표 리스트
- GridSystem.CalculatePath(): 사각형 경로 알고리즘 구현 (상세 주석 참고)
- Enemy.Update(): pathPoints 따라 이동, 마지막 도달 시 AttackCore()
- EnemySpawner.Update(): 웨이브 시간 체크 및 SpawnWave()
- EnemySpawner.SpawnScaledWave(): 공식 2.8 적용

### 완료 기준
```
1. 외곽 랜덤 위치에서 적 생성
2. 적이 사각형 경로를 따라 중앙으로 이동
3. 중앙 도달 시 코어 공격 후 사라짐
4. 웨이브 종료 후 스케일링된 적 무한 생성
```

## 📦 **SET 4: 디펜스 시스템** (게임 핵심 3)
**담당자: 1명**  
**예상 시간: 4-5시간**  
**의존성: SET 1, SET 3 완료 필요**

### 파일 목록
1. `DefenseManager.cs` - 검 배치 및 정렬
2. `SwordSlot.cs` - 자동 공격 로직
3. `CoreHealth.cs` - 코어 HP 및 회복
4. `DangerSystem.cs` - Danger 판정
5. `SwordVisualController.cs` - 이펙트
6. `DefenseUI.cs` - 코어 HP바, 검 리스트

### 구현 내용
- DefenseManager.PlaceSword(): 검 추가, 전투력 정렬, 최하위 삭제
- SwordSlot.TryAttack(): 범위 내 적 탐색, 진행도 높은 적 공격
- CoreHealth.Update(): 자동 회복, TakeDamage() 구현
- DangerSystem.CheckDanger(): 적 진행도 체크, 75% 초과 시 알림
- DefenseUI: 코어 HP바 실시간 업데이트

### 완료 기준
```
1. 검 배치 시 전투력 순으로 정렬
2. 배치된 검이 1초마다 가장 위협적인 적 공격
3. 적 처치 시 골드 획득
4. 적이 코어 공격 시 HP 감소, 0 도달 시 게임오버
5. 적 진행도 75% 초과 시 Danger 상태 전환
```
